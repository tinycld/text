## Inline formatting

| Shortcut | Action |
|---|---|
| **⌘B** | Bold |
| **⌘I** | Italic |
| **⌘U** | Underline |
| **⌘`** | Inline code — see [Formatting code](help://text:code-blocks) |
| **⌘K** | Insert / edit a link |
| **⌘Z** / **⌘⇧Z** | Undo / Redo |

## Block formatting

| Shortcut | Action |
|---|---|
| **⌘⇧L** | Align left |
| **⌘⇧E** | Align center |
| **⌘⇧R** | Align right |
| **⌘⇧J** | Justify — see [Aligning and indenting paragraphs](help://text:alignment-indent) |
| **⌘]** | Increase indent |
| **⌘[** | Decrease indent |
| **⌘⇧`** | Toggle code block |

## Navigation & document

| Shortcut | Action |
|---|---|
| **⌘F** | Find / Replace |
| **⌘P** | Print |
| **⌘/** | Open this list |
| **/** | Open the slash menu — see [Inserting blocks with the slash menu](help://text:slash-menu) |

## On Windows / Linux

Substitute **Ctrl** for **⌘** in every shortcut above.
