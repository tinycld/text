## To open the slash menu

Type `/` at the start of a paragraph or after a space. A floating menu appears with block-insertion commands.

## To pick a command

- **Filter by typing** after the `/`. Matching is case-insensitive against the command label and a small set of keywords — `/h` shows the headings, `/code` shows code block, `/img` shows image.
- **↑ / ↓** to move the highlight.
- **Enter** to apply. The `/query` text is removed and the block is inserted.
- **Esc** or **click outside** to dismiss without inserting.

## Commands available

| Command | What it does |
|---|---|
| Heading 1 / 2 / 3 | Sets the current paragraph to a heading at the chosen level |
| Bullet list | Starts a bulleted list |
| Numbered list | Starts a numbered list |
| Quote | Wraps the line in a blockquote |
| Code block | Converts the line to a fenced code block (see [Code blocks](help://text:code-blocks)) |
| Table | Inserts a 3 × 3 table with a header row |
| Image | Opens the image picker — see [Inserting images](help://text:images) |
| Horizontal rule | Inserts a divider line |
